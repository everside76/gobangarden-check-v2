# 고반가든 MOT 점검 웹앱 V2

👉 **앱 주소: https://everside76.github.io/gobangarden-check-v2/**

매장에서 스마트폰으로 **MOT(Moment of Truth) 서비스 체크리스트**를 점검하고, 결과를 구글 스프레드시트에 자동 저장하는 모바일 웹앱입니다.

**V2의 가장 큰 변화 — 체크리스트를 구글 시트에서 직접 불러옵니다.**
문항·배점·판정 기준을 시트에서 고치면 앱이 그대로 따라갑니다. 코드를 고칠 필요가 없습니다.

> 📌 V1(`고반가든_MOT_체크리스트` 폴더)은 그대로 운영됩니다. V2는 완전히 별개의 앱·시트·스크립트를 씁니다.

## V1 → V2 달라진 점

| | V1 | V2 |
|---|---|---|
| 문항 관리 | 코드에 하드코딩 | **구글 시트에서 실시간 로딩** |
| 채점 | 감점제 (100점에서 깎음) | **획득점수제 ('일반' 21문항 = 100점)** |
| 상황 문항 | 없음 | **'상황발생시' 12문항 — 발생 시에만 점검, 불이행일 때 −1 또는 −2** |
| 문항 구분 | 단일 | **일반/상황발생시 · 개인/매장공통 2축** |
| 판정 기준 | 일부만 표시 | **문항별 이행·미흡·불이행 기준 전부 표시** |
| 주문방식 | 직접주문/테이블오더 분기 | **폐지 — 단일 체크리스트** |
| 문항 수 | 8단계 35문항 | 9단계 33문항 |

## 점수 계산

```
① '일반' 21문항        이행 = 시트의 이행 점수 (합계 100)
                       미흡 = 시트의 미흡 점수 (대개 절반)
                       불이행 = 0
                       해당없음·미응답 = 채점 제외 (분모에서도 빠짐)
   기본점수 = 획득합계 ÷ 채점대상 만점 × 100

② '상황발생시' 12문항   기본은 '상황 없었음' — 채점 무관
                       발생 시에만 판정, 불이행일 때 −2 또는 −4

③ 절대 금지 10계명     위반 1건당 −5 (시트에서 조정 가능)

최종점수 = 기본점수 − 상황감점 − 10계명감점   (0~100)
등급 = S 90 / A 80 / B 70 / C 60 / D 50 / F
```

**점검율**: (일반 21문항 − 해당없음 − 미응답) ÷ 24
점검율이 낮으면 등급에 상한이 걸립니다 — 80%↑ 제한없음 / 60%↑ A / 50%↑ B / 50%미만 C(재점검 대상).
상한은 등급을 낮추기만 하고 올리지는 않습니다.

## ⚠️ 코드를 고쳐 배포할 때

`index.html` 안의 `?v=` 값을 **모두 새 버전으로 바꿔서** 커밋하세요.

```html
<link rel="stylesheet" href="css/app.css?v=2.0.1" />
...
<script src="js/config.js?v=2.0.1"></script>
```

이 값을 바꾸지 않으면 브라우저가 예전 `js`·`css`를 계속 써서, 화면만 새것이고 코드는 옛것인 상태가 됩니다.
`js/config.js`의 `APP_VERSION`과 같은 값으로 맞춰 두면 헷갈리지 않습니다.

사용자 쪽에서 화면이 갱신되지 않으면 앱 **⚙️ 설정 → 앱 최신 버전 받기** 를 누르면 됩니다.
